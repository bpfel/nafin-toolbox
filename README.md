# nafin-toolbox

A self-hosted personal finance app built for Switzerland. Plan a budget, alone
or shared with a partner, route every line of it to the account that pays or
saves it, and print Swiss QR bills. Your financial data is encrypted in the
browser before it is saved, so the server can read none of it. Installable on a
phone, and available in German, French, Italian and English.
